# 电视开机广告开关实施计划

> 按执行顺序实现并验证；设计依据为 `docs/superpowers/specs/2026-10-28-desktop-design.md`。

**目标：** 交付可在 macOS、Windows 上运行的开源桌面工具，安全处理有证据支持的电视固件。

**结构：** `src/tvboot/adb.py` 管理独立 ADB 服务和设备读取；`profiles.py` 管理严格的固件匹配；`core.py` 实施读取、备份、修改、恢复；`discovery.py` 发现并校验局域网电视；`bridge.py` 提供受限的桌面界面接口；`ui/` 是本地 HTML 界面。测试放在 `tests/`，构建资源及构建流程分别放在 `scripts/` 和 `.github/workflows/`。

## 核验重点

1. 未知型号、固件或桌面版本以及无法识别的设备不得触发写入。
2. 断线、授权失败、异常原值、备份失败和写后校验失败不得显示成功。
3. 先保存实际原值，重复执行不得覆盖原始备份；恢复仅针对同一设备、同一固件和预期当前状态。
4. 网络发现只读取响应的合法局域网描述；输入 IP 不执行 shell 拼接；不得操作其他设备或终止系统已有 ADB 服务。
5. 分发包自带可运行的 ADB 和相应许可；不在仓库提交真实设备标识、本机私有记录或电视系统文件。
