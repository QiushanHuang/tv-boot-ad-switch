# Third-party components

Release packages include or use the following components. The full notices are in this directory or, for Android Platform-Tools, in the bundled `adb/NOTICE.txt`.

- [Android Debug Bridge](https://android.googlesource.com/platform/packages/modules/adb/) from Google Android Platform-Tools 37.0.1, with its accompanying notices.
- [Python](https://www.python.org/) 3.12, Python Software Foundation license.
- [pywebview](https://github.com/r0x0r/pywebview), BSD 3-Clause; [Bottle](https://github.com/bottlepy/bottle), MIT; [proxy_tools](https://github.com/jtushman/proxy_tools), MIT.
- On macOS: [PyObjC](https://github.com/ronaldoussoren/pyobjc), MIT.
- On Windows: [pythonnet](https://github.com/pythonnet/pythonnet), [clr-loader](https://github.com/pythonnet/clr-loader), [cffi](https://github.com/python-cffi/cffi), and [pycparser](https://github.com/eliben/pycparser), subject to their included licenses. Microsoft WebView2 Runtime is supplied separately by the user's operating system or Microsoft.
- [typing_extensions](https://github.com/python/typing_extensions), Python Software Foundation license.
- [Lucide](https://lucide.dev/), MIT, for interface icons.
- [PyInstaller](https://pyinstaller.org/), GPL with the bootloader exception described in its included license.
